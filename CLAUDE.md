## Project Overview

This is a Jekyll-based personal blog/website (vertis.io) with custom TypeScript utilities for image management and content processing. The site uses TailwindCSS for styling and includes Cloudflare Images integration for CDN-hosted images.

## Development Commands

### Running the Site

The site is being migrated from Jekyll to Astro (see `site/`). The Jekyll
site at the repo root is the legacy version, kept for comparison during the
migration.

```bash
# Astro dev server (the new site)
cd site && bun run dev

# Astro production build (outputs to site/dist)
cd site && bun run build

# Re-run the Jekyll -> Astro content migration
bun run _bin/migrate-to-astro.ts

# Legacy: Jekyll development server
jekyll serve

# Legacy: Build CSS with TailwindCSS
npm run build-css
```

### Content Management
```bash
# Create a new blog post
./_bin/new-post.sh "Post Title"

# Copy content from Obsidian
./_bin/copy-from-obsidian.sh

# Generate related content embeddings
python _bin/related-content.py
```

### Image Management
```bash
# Sync images to Cloudflare CDN
bun run _bin/sync-images.ts

# Upload a single new image
bun run _bin/sync-new-image.ts

# Replace local image URLs with CDN URLs in posts
bun run _bin/chore-image-to-cdn.ts

# Add preview URLs to posts
bun run _bin/chore-add-preview-url.ts
```

## Architecture

### Content Structure
- **_posts/**: Blog posts in Markdown format with Jekyll frontmatter
- **_pages/**: Static pages (about, contact, consulting)
- **_layouts/**: Jekyll layout templates (default, post, page, blog)
- **_includes/**: Reusable Jekyll components
- **_data/**: Data files including `related_content.yml` generated by ChromaDB

### Styling System
- TailwindCSS configured via `tailwind.config.cjs`
- PostCSS pipeline in `postcss.config.cjs`
- Custom styles in `_src/new-styles.css`
- Compiled output goes to `assets/css/new-styles-compiled.css`

### Image Pipeline
- Local images stored in `assets/img/`
- TypeScript utilities in `_bin/` handle Cloudflare Images upload
- `uploadResults.json` tracks uploaded images to prevent duplicates
- Environment variable `CLOUDFLARE_IMAGES_API_TOKEN` required for uploads

### Related Content System
- Uses ChromaDB to generate content embeddings
- Python script creates similarity vectors for all posts
- Results stored in `_data/related_content.yml`
- Displays related posts based on semantic similarity

## Environment Variables

Required in `.env`:
- `CLOUDFLARE_IMAGES_API_TOKEN`: API token for Cloudflare Images uploads

## Dependencies

- **Ruby**: Jekyll 4.3, jekyll-paginate
- **Node/Bun**: TailwindCSS, PostCSS, TypeScript utilities
- **Python**: ChromaDB for content embeddings
