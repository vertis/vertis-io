## Project Overview

This is an Astro-based personal blog/website (vertis.io) with custom TypeScript utilities for image management and content processing. The site uses TailwindCSS for styling and includes Cloudflare Images integration for CDN-hosted images. It was migrated from Jekyll to Astro (see `_bin/migrate-to-astro.ts` for the one-time migration script).

## Development Commands

### Running the Site

```bash
# Astro dev server
bun run dev

# Astro production build (outputs to dist/)
bun run build
```

### Content Management
```bash
# Create a new blog post
./_bin/new-post.sh "Post Title"

# Copy content from Obsidian
./_bin/copy-from-obsidian.sh

# Generate related content embeddings (writes src/data/related-content.json)
# Requires Ollama running locally: `ollama serve` + `ollama pull qwen3-embedding:8b`
bun run related-content
```

### Image Management
```bash
# Sync images to Cloudflare CDN
bun run _bin/sync-images.ts

# Upload a single new image
bun run _bin/sync-new-image.ts

# Replace local image URLs with CDN URLs in posts
bun run _bin/chore-image-to-cdn.ts

# Add preview URLs to posts
bun run _bin/chore-add-preview-url.ts
```

## Architecture

### Content Structure
- **src/content/posts/**: Blog posts in Markdown with frontmatter (Astro content collection)
  - URL scheme preserved from Jekyll: `/YYYY/MM/DD/<slug>/`, case-sensitive
  - Legacy Tumblr permalinks via `permalink:` frontmatter -> `/post/<id>/<slug>/`,
    with static `.html` redirect stubs in `public/post/`
  - Drafts are posts with `published: false` (excluded from routes/feed)
- **src/pages/**: Routes - index, blog index + pagination, `[...slug].astro` post catch-all
- **src/layouts/**: Base, Post, Page layouts
- **src/components/**: Header, Footer, BlogItem, Pagination, UkraineBanner
- **src/data/**: `related-content.json` generated by `_bin/related-content.ts`

### Styling System
- TailwindCSS configured via `tailwind.config.mjs` (with @tailwindcss/typography)
- Global styles in `src/styles/global.css`
- Code highlighting via Shiki (github-dark theme), replacing old Pygments setup

### Image Pipeline
- Local images stored in `public/assets/img/`
- TypeScript utilities in `_bin/` handle Cloudflare Images upload
- `uploadResults.json` tracks uploaded images to prevent duplicates
- Environment variable `CLOUDFLARE_IMAGES_API_TOKEN` required for uploads

### Related Content System
- Uses local embeddings via Ollama (`qwen3-embedding:8b`) — no Python, no API keys
- `_bin/related-content.ts` embeds the full text of each post (HTML/code
  stripped) with a 32k-context model and stores the top 5 similar posts above
  a cosine-similarity threshold in `src/data/related-content.json`
- Drafts (`published: false`) are excluded; JSON is committed and read at build
  time by `src/utils/posts.ts`, so Ollama is only needed when regenerating
- Displays related posts on post pages via `src/layouts/Post.astro`

## Environment Variables

Required in `.env`:
- `CLOUDFLARE_IMAGES_API_TOKEN`: API token for Cloudflare Images uploads

## Deployment

Static site deployed to https://vertis.io via Vercel. Vercel auto-detects Astro (build command `astro build`, output directory `dist`).

## Dependencies

- **Bun**: Astro 5, TailwindCSS, TypeScript utilities
- **Ollama** (local, optional): only needed to regenerate `related-content.json`
